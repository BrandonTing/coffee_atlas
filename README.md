# Coffee Atlas

**Turn every cup into an experiment, and every experiment into knowledge.**

Coffee Atlas is an AI-native, mobile-first coffee learning and brewing journal. Start with a bean label photo or description, explore its origin and processing, discuss a suggested recipe, reflect on an actual brew, and confirm an editable structured record before saving.

## Project status

The application has not been scaffolded yet. Implementation begins with [Issue #2 — Foundation](https://github.com/BrandonTing/coffee_atlas/issues/2).
